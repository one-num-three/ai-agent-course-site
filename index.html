📚 每课学生资料 & Prompt 宝典

学生上课必备的实操任务单、提示词填空框与通关 Checkpoint

📋 第 1 课：第一个网页初始化提示词卡片

开箱即用 Prompt

复制下方框内提示词，修改 【 】 内的主题与文字，发送给 Antigravity Agent：

请帮我把当前网页改造成一个以【我的世界探险日志】为主题的网页。
要求：
1. 修改 header 区域的大标题为【我的世界探险日志】；
2. 在副标题写上一句介绍："【记录我的每一个建筑与红石机械】"；
3. 将主按钮文本改成【查看我的作品】；
4. 保持页面整体样式美观，不要删除现有的 style.css 链接。

🔍 指挥官自查 Checkpoint：

  • ✅ 点击预览是否看到标题正确变成了你的自定义主题？
  • ✅ 页面上的按钮点击是否有响应弹窗？
  • ✅ Git 界面输入 Commit 信息：feat: 完成我的第一个个人网页 V1.0 并 Push 存档。

🎨 第 2 课：区域样式重构与深色模式 Prompt

进阶交互 Prompt

提示词 1：区域视觉重构（限制只改 CSS，防止误删 HTML）

请只修改 `style.css` 文件：
1. 为 `.card` 卡片加上圆角 (border-radius: 16px) 和悬浮上升效果 (hover 时 transform: translateY(-4px)，带阴影)；
2. 为整个页面使用更柔和的现代背景色 (#f4f6f8)；
3. 请不要修改 `index.html` 中的节点和 ID 命名。

提示词 2：添加深色/浅色模式切换按钮

请在 `index.html` 的 header 中加一个【深色/浅色模式切换按钮】，并在 `script.js` 中添加点击逻辑：
1. 点击按钮时在 ☀️ 浅色模式 与 🌙 深色模式 之间切换；
2. 在 `style.css` 中为深色模式定义深蓝色背景 (#0f172a) 与纯白文字 (#ffffff)。

提示词 3：📱 手机移动端响应式适配

请检查 `style.css`，添加 `@media (max-width: 768px)` 媒体查询：
当屏幕宽度小于 768px 时，把 `.card-grid` 改为单列布局 (grid-template-columns: 1fr)，确保手机端无横向滚动条。

📊 第 3 课：NotebookLM 大纲解析与 Gemini 矢量插画 Prompt

视觉与内容 Prompt

1. NotebookLM 6 页 PPT 大纲提炼提示词

请分析我上传的项目文档，帮我提取一份 6 页 PPT 大纲。
要求：
1. 第 1 页：项目名称与核心痛点（一句话吸引听众）；
2. 第 2-3 页：核心功能与网页技术亮点；
3. 第 4-5 页：我与 AI Agent 协作解决问题的过程；
4. 第 6 页：未来规划与致谢。
每页只输出【标题】和【3 个精简要点】。

2. Gemini Nano Banana 风格统一矢量插画 Prompt

极简科技插画风，主题为【一个正在与 AI Agent 共同编写代码的少年】，
扁平矢量设计，深蓝色与紫色渐变色调，柔和光影，高清，画面中不要出现任何文字，画面右侧留出 40% 的排版空白。

💻 第 4 课：本地 Hermes Agent 启动与操控指令

本地 Agent Prompt

1. 本地 Agent 启动与诊断命令

# 在 Antigravity 终端运行启动
hermes start

# 查看本地 Agent 诊断状态
hermes status

2. 本地 Agent 网页维护任务指令

指令：维护并更新本地网页
请读取我的 index.html 文件：
1. 检查页面中现有的卡片列表；
2. 在卡片列表中新增一张卡片，标题为【本地 Hermes Agent 启动成功！】；
3. 内容写上【这个卡片是由运行在我电脑上的本地 Agent 自动修改写入的！】；
4. 保持 CSS 样式不受破坏。

3. 本地日志盘点命令

# 查看最后 10 行本地工具调用日志
hermes logs -n 10

🎤 第 5 课：项目健康巡检与 3 分钟 Demo 答辩讲稿结构

答辩与巡检 Prompt

1. 项目一键自动健康巡检指令

指令：巡检项目健康度
请读取我的 student-project 文件夹，检查 index.html、style.css 和 script.js 是否正常存在，并把巡检报告追加写在 docs/test-report.md 中。

  4. [02:30 - 03:00] 工程思维总结：阐述人机协作的边界与安全防线感悟。
